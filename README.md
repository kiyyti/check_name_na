# check name na

ระบบเช็คชื่อเข้าเรียน **วิชาเดียว** สำหรับผู้เรียนประมาณ 300 คน ใช้ Google Sheets เก็บข้อมูล

ข้อกำหนดล่าสุด: ไม่ใช่ระบบลงเวลาพนักงาน ไม่มี OT กะงาน หรือเงินเดือน แต่ละครั้งที่เรียนเป็นหนึ่ง Session และเช็ค มา / สาย / ขาด / ลา รายผู้เรียน

ไฟล์ฐานข้อมูลปัจจุบัน: `spreadsheet/check-name-na-structure.xlsx` มี 7 แท็บ: StartHere, Settings, Students, Sessions, Attendance, AuditLog, Dictionary

ใช้ `tools/build.mjs` สร้างโครงสร้าง class-v2 ใหม่ คงชื่อวิชาและภาคเรียนให้กรอกตามจริง

`web/` มีหน้าเช็คชื่อ หน้า QR และ API proxy แล้ว `google-apps-script/Code.gs` เก็บข้อมูลใน Google Sheets ดูวิธีเชื่อมใน `google-apps-script/SETUP.md`

กฎ: ใช้เวลาเซิร์ฟเวอร์ Asia/Bangkok แต่ละรอบกำหนดเวลาเข้าสาย–ขาดและสถานที่ได้เอง รอบเดิมที่ยังไม่ได้กำหนดแยกใช้ Settings เป็นค่าเริ่มต้น QR เปิดเว็บ แล้วกรอกชื่อเต็มหรือรหัสนักศึกษาและระดับชั้น เทียบกับรายชื่อที่ครูใส่ไว้ และตรวจพิกัด GPS ก่อนบันทึก

สถานที่: วิทยาลัยการอาชีพเถิน จ.ลำปาง ผู้สอน: อาจารย์ปภังกร บุตรศรี

หน้าเว็บเชื่อม Google Sheets ผ่าน Apps Script แล้ว เจ้าของเป็นผู้เผยแพร่ผ่าน GitHub/Vercel การเปลี่ยนแปลงในเครื่องต้อง push และรอ deployment ใหม่ก่อนจึงจะใช้บนเว็บจริง

เพิ่มหน้าแอดมินที่ `/admin` สำหรับบัญชีเดียว จัดการนักเรียน รอบเรียน ค่าเริ่มต้น และแก้ผลเช็คชื่อพร้อม AuditLog รองรับเวลา/พิกัดแยกต่อรอบ คัดลอกและสร้างรอบล่วงหน้า อ่านขั้นตอนเปิดใช้งานใน `ADMIN-SETUP.md` ก่อน deploy เวอร์ชันนี้ ต้องอัปเดต Apps Script และเพิ่มค่า ADMIN_* ใน Vercel ด้วย

ไฟล์ส่วนตัว `web/.env.admin.vercel` มีค่าแอดมินสำหรับตั้งใน Vercel ห้าม commit รหัสผ่านจริงไม่อยู่ใน source code เซสชันล็อกอินใช้ cookie ที่ลงลายเซ็นและหมดอายุใน 8 ชั่วโมง

ทดสอบ: `node --test google-apps-script/logic.test.mjs` ใช้ข้อมูลจำลองในหน่วยความจำ ไม่เรียกบัญชี Google จริง การทดสอบผ่านไม่ใช่ผลทดสอบโหลด 300 คนพร้อมกัน

ทดสอบแอดมิน: `node --test web/lib/admin-session.test.mjs` ตรวจรหัสผ่านและเซสชัน และหลัง `npm run build:vercel` ใน web ให้รัน `node --test tools/admin-http.test.mjs` จากโฟลเดอร์หลักเพื่อทดสอบ API จริงผ่านเซิร์ฟเวอร์ชั่วคราวบนพอร์ต 3197 ใช้ gateway จำลอง ปิดการเรียก Google จริงทั้งหมด

มี WebMCP prepare_checkin สำหรับกรอกฟอร์มโดยไม่บันทึก ไม่ได้ทดสอบสัญญา WebMCP ในเบราว์เซอร์ เพราะไม่มี browser context ที่พร้อมใช้งาน
