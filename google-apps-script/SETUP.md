# เชื่อม check name na กับ Google Sheets

## สถานะ
โค้ดและไฟล์ชีตพร้อมสำหรับการตั้งค่า ยังไม่ได้เชื่อมบัญชี Google จริง ยังไม่ได้เผยแพร่เว็บสำหรับนักเรียน และยังไม่ทดสอบโหลดพร้อมกัน 300 คน

## 1. Google Sheets
นำเข้า `../spreadsheet/check-name-na-structure.xlsx` เป็น Google Sheets ตามขั้นตอนเดิม ใช้รุ่น **class-v2** เท่านั้น ถ้ามีรายชื่อจริงในชีตเก่า ให้ย้ายคอลัมน์เดิมตามชื่อ อย่านำเข้าทับข้อมูลจริง

ตั้ง File > Settings > Time zone เป็น Asia/Bangkok แล้วกรอก:

- Settings: ชื่อวิชา ภาคเรียน ชื่อห้อง latitude longitude radius_m และ max_accuracy_m (เมตร)
- Students: รหัสถาวร รหัสนักศึกษา ชื่อ class_level และ status = active ไม่เก็บรหัสผ่าน
- Sessions: หนึ่งแถวต่อวันที่เรียน ระบุ session_id, starts_at, ends_at, checkin_opens_at, checkin_closes_at, status = open และ class_level/group_name หากจำกัดกลุ่ม

ต้องใช้เซลล์วันเวลาจริงใน Sessions ไม่ใช่ข้อความคลุมเครือ วันเวลาเปิดต้องไม่หลังเวลาเริ่ม และเวลาปิดต้องหลังเวลาเปิด หากต้องการให้ผู้มาหลัง 09:00 ได้รับผลขาดและบันทึกพิกัด ให้เปิดรอบต่อไปถึงเวลาเลิกเรียน ไม่ปิดรับคำขอที่ 09:00

## 2. Apps Script
ในชีตเลือก Extensions > Apps Script วางไฟล์ `Code.gs` ตั้งเขตเวลาโปรเจกต์เป็น Asia/Bangkok

ใน Project Settings > Script properties เพิ่ม:

- `SPREADSHEET_ID`: ส่วนระหว่าง `/d/` และ `/edit` ในลิงก์ชีต
- `API_SECRET`: ค่าสุ่มที่เดายากอย่างน้อย 32 ตัวอักษร เก็บเฉพาะใน Script properties และค่าลับของเซิร์ฟเวอร์เว็บ ไม่ส่งในแชต ไม่ใส่ชีตหรือ frontend

Deploy > New deployment > Web app ให้ทำงานในนามเจ้าของ และตั้งให้เซิร์ฟเวอร์เรียกได้ (`Anyone` ถ้าบัญชีอนุญาต) ตัวสคริปต์ตรวจ API_SECRET ทุกคำขอ ชีตยังคงแชร์แบบจำกัด ห้ามส่ง OAuth token ให้เว็บฝั่งผู้เรียน

คัดลอก URL ที่ลงท้าย `/exec` เป็น `GOOGLE_APPS_SCRIPT_URL` ของเว็บ ตั้งค่าลับ `GOOGLE_APPS_SCRIPT_SECRET` ให้ตรงกัน สำหรับเครื่องนี้ใช้ `web/.env` แล้ว restart server สำหรับเว็บเผยแพร่ใช้ runtime secrets ของโฮสต์

หลังแก้สคริปต์ให้สร้างเวอร์ชันใหม่ใน deployment เดิม

## 3. สรุปผู้ขาดเรียน
ใน Apps Script > Triggers เพิ่ม trigger สำหรับ `finalizeAbsences` แบบ time-driven ทุก 5 นาที และอนุญาตให้เข้าถึงชีต

ตั้งแต่ 09:00 เวลาไทย ฟังก์ชันเพิ่มขาดให้ผู้เรียนที่ยังไม่มีรายการในรอบเรียนของวันนี้ ไม่ทับผลเดิม และไม่รวมรอบ cancelled/draft หรือผู้ที่อยู่นอกกลุ่ม/ช่วงวันที่เรียน งาน trigger อาจทำงานช้ากว่า 09:00 ตามเวลารันจริง ส่วนคำขอผ่านเว็บตั้งแต่ 09:00 ตัดเป็นขาดทันที

## กฎที่เขียนไว้
- ก่อน 08:30:00 = มาเรียน; 08:30:00–08:59:59 = มาสาย; ตั้งแต่ 09:00:00 = ขาด
- ใช้เวลาที่ Apps Script รับคำขอ ไม่เชื่อเวลาบนนาฬิกาผู้เรียน
- ตรวจชื่อเต็มหรือรหัสตรงกับระดับชั้น ชื่อซ้ำต้องใช้รหัส ไม่มีการสร้างนักเรียนเองจากฟอร์ม
- ต้องมีรอบเรียนวันนี้ที่เปิดอยู่และตรงกลุ่ม/ระดับชั้น ไม่สร้างรอบให้เองในวันหยุด
- รัศมีตรวจด้วยระยะทางจริง และกำหนดให้ distance + accuracy <= radius; GPS ไม่ยืนยันชั้นอาคารหรือห้องได้แน่นอน
- ก่อนบันทึกใช้ Script Lock และตรวจคู่ session_id/student_id ป้องกันกดซ้ำและข้อมูลชนกัน
- ไม่ใช้ localStorage เป็นฐานข้อมูล; หน้าเว็บแสดงสำเร็จเมื่อได้รับคำยืนยันจากชีตแล้ว
- ครูเป็นผู้แก้สถานะลา/ข้อมูลผิดในชีตและบันทึก AuditLog ด้วยตนเอง ยังไม่มีหน้าจัดการครู

ชื่อหรือรหัสที่ผู้เรียนกรอกเป็นการเทียบรายชื่อ ไม่ใช่การพิสูจน์ตัวตนที่กันสวมชื่อได้ QR เป็นลิงก์เข้าเว็บและส่งต่อกันได้ GPS ของเว็บก็ถูกปลอมจากอุปกรณ์ได้ หากต้องกันเช็คแทน ต้องเพิ่มวิธียืนยันที่ตกลงกับผู้ใช้ก่อน

## QR และการเปิดใช้
ใช้ HTTPS ที่มือถือเข้าถึงได้ หน้า `/qr` สร้างและพิมพ์ QR ของเว็บจริง ไม่แจก QR localhost ให้นักเรียน

ก่อนเปิดจริงทดสอบกับรายชื่อทดสอบ: 08:29:59, 08:30:00, 08:59:59, 09:00:00; พิกัดนอก/ขอบพื้นที่; ไม่อนุญาต GPS; ชื่อซ้ำ; กดซ้ำ; ครูปิดรอบ; ชีตเชื่อมต่อไม่ได้ และโหลดพร้อมกันจริง สำหรับ 300 คนอาจต้องปรับสถาปัตยกรรมคิวตามผลทดสอบและโควตาบัญชี
